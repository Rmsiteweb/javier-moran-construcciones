# Javier Morán Construcciones

Sitio web profesional para **Javier Morán Construcciones**, El Calafate, Santa Cruz, Patagonia Argentina.

## 🌐 Ver el sitio
Una vez publicado en GitHub Pages, el sitio estará disponible en:
`https://TU-USUARIO.github.io/jmc-construcciones`

## 📁 Estructura del proyecto
```
jmc-construcciones/
├── index.html        ← Página principal
├── css/
│   └── style.css     ← Todos los estilos
├── js/
│   └── app.js        ← Toda la lógica
├── assets/           ← Carpeta para imágenes futuras
└── README.md         ← Este archivo
```

## 🔓 Zona Pública
- **Inicio** — Presentación del negocio
- **Contacto** — WhatsApp, teléfono y ubicación

## 🔒 Zona Privada (requiere contraseña)
- **Presupuestos** — Crear, guardar y exportar a Excel/PDF
- **Agenda** — Registro de clientes, exportar a Excel/PDF
- **Fotos Destacadas** — Gestionar el banner de la página principal

## 📱 Compatible con
- Celular (Android / iPhone)
- Computadora (Windows / Mac)
- Cualquier navegador moderno

## ⚙️ Sin instalaciones
No requiere instalar ningún programa. Solo necesita conexión a internet para cargar los íconos, fuentes y herramientas de exportación.

## 🔧 Cómo cambiar la contraseña
Abrí `js/app.js` con el Bloc de Notas y buscá la línea:
```js
const PRIVATE_PASS = '...';
```
Cambiá el valor entre comillas por tu nueva contraseña.
